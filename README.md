네버윈터 나이츠 2 인핸스드 에디션 한국어 패치 — 영문 보완 검수본

대상: 확인한 PC판 1.1.1.0의 영문 리소스.
게임 안의 언어 설정은 English로 선택해 주세요.

기존 본편·배신자의 가면·제히르의 폭풍 번역을 EE에 이식했습니다.
웨스트게이트는 기존 모듈과 HWP 번역을 옮겼으며, HWP에서 1,378개 항목을 복원했습니다.
EE 추가 문구 684개와 한글 글꼴 13개를 포함합니다.
이번 보완에서는 이전 검수본에 남아 있던 영문 3,362개 항목에 한국어를 추가 반영했습니다.
본편·확장팩 2,319개, 웨스트게이트 1,043개이며, 기존 번역 재사용과 새 번역을 함께 적용했습니다.
대사·일지·책·장비·인물 설명, 메뉴와 휴식·이동 안내 등을 보완했습니다.

유지한 영문과 검수 범위

퍼즐의 대응 기호(Nix, One 등), 주문의 무의미한 발음 구절, SUNLIGHT/GARLIC,
LAN/PvP/HDR 같은 약어는 의도적으로 유지했습니다.
개발·디버그용 문구와 보이지 않는 도우미·배경 리소스의 이름은 플레이용 번역과 구분했습니다.
사용처가 확인되지 않은 구형 문자열도 남아 있으므로, 파일의 영문 항목 수가 곧 플레이 중 미번역 수는 아닙니다.
실제 화면·플레이 검수와 기존 번역 전체의 의미·문체 검수는 아직 남아 있습니다.

설치

1. 게임과 툴셋을 종료합니다.
2. ZIP 전체를 별도 폴더에 풉니다.
3. 한글패치.exe를 더블클릭합니다.
4. 자동으로 찾은 게임 폴더를 확인합니다. 찾지 못했다면 “찾아보기”로 nwn2.exe가 있는 폴더를 선택합니다.
5. “한글패치 설치”를 누르고 완료될 때까지 기다립니다.

이전 검수본을 이미 설치했다면, 새 ZIP의 한글패치.exe에서 먼저 “원본 복구”를 누른 다음
“한글패치 설치”를 눌러 갱신해 주세요. 예전 NWN2_Korean_Backup 폴더가 있어야 합니다.

Python 설치나 명령어 입력은 필요하지 않습니다.
설치 전 변경할 파일을 모두 백업하고 적용합니다.
백업은 게임 폴더의 NWN2_Korean_Backup 안에 보관되므로 압축을 푼 폴더를 지워도 복구할 수 있습니다.

원본 복구

한글패치.exe를 실행하고 게임 폴더를 확인한 다음 “원본 복구”를 누릅니다.
해당 게임 폴더에 보관된 최신 백업을 찾아 복구합니다.
